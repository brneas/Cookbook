# Changelog

## 1.0.0

### Added

- Direct Nextcloud Cookbook connection with browser sign-in and app-password fallback.
- Recipe List/Grid, search, categories, keywords, editing, deletion, URL import and Nextcloud Files image selection.
- Offline recipe access, queued synchronization and conflict/uncertain-operation review.
- Recipe and Focus Cooking views, local progress, serving adjustments and persistent timers with optional notifications.
- Local ingredient preparation checks, safe editor reordering and accessible move controls.
- Nextcloud instance theming, light/dark appearance and responsive layouts.

### Security / Reliability

- HTTPS-only transport, scoped credentials, Android secure storage and sanitized authentication diagnostics.
- Patched Kotlin build tooling and local production-signing verification.
- Transactional migrations, unknown-field preservation and conservative mutation recovery.
- Disabled Android backups, bounded image caching/decoding and an explicit Skia compatibility setting.
